# Risk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Risk (`packages/games/risk`) to Jackdaw: two maps, secret missions or world domination, Roll/Blitz attacks, phone + TV screens.

**Architecture:** Pure rules over a map graph (`MapDef`) in `@jackdaw/game-risk`; public state through `getTableView`, hands/missions/drafts only through `getPlayerView`. Screens in `src/ui/` draw an SVG map with pan/zoom from the same `MapDef`. Maps' outlines come from a dev-only generator script whose output is committed.

**Tech Stack:** TypeScript, Zod 4.6.7, Vitest, React 19, Next.js 16, Playwright. Dev-only: `d3-delaunay`, `polygon-clipping` (script only).

**Spec:** `docs/superpowers/specs/2026-10-18-risk-design.md`. Read it with this plan.

## Global Constraints

- No change to `GameModule`, the lobby state machine or the protocol (`packages/engine`).
- All randomness through the injected `Rng` (`next`, `int`, `pick`, `shuffle`); no `Math.random`, no clock reads in rules (use `now` args).
- `getTableView` carries no hands, missions (until `phase === 'over'`), unrevealed drafts or deck order.
- Options, exactly: `map: ['World','Realm']`, `goal: ['Secret missions','World domination']`, `setup: ['Quick','Draft']`, `cardSets: ['Rising','Fixed']`, `turnTimer: ['Off','1 minute','2 minutes','3 minutes']`; defaults World, Secret missions, Quick, Rising, Off.
- Meta: id `risk`, name `Risk`, 2–6 players, category `board`, minutes `[45, 180]`, complexity 2.
- Starting armies: 2p 40 (neutral 40 too), 3p 35, 4p 30, 5p 25, 6p 20.
- Rising set values 4, 6, 8, 10, 12, 15, then +5; Fixed: 3 infantry 4, 3 cavalry 6, 3 artillery 8, one of each 10.
- No literal colours outside token files; tokens from `packages/ui`; Tailwind for layout only; tap targets ≥ 44px; respect `prefers-reduced-motion`; check 375/768/1280/1920 in day and dark.
- Commits authored as Lesia with **no** Co-Authored-By trailer. Before each commit: `pnpm format:check && pnpm lint && pnpm typecheck && pnpm test` (plus `pnpm build:check` when web code changed). In Git Bash run `export PATH="$HOME/.local/bin:$PATH"` first.
- Credit line: "Based on Risk by Albert Lamorisse."

## Review Focus

1. A stale or replayed move (double-tapped Roll, a second `reinforce` after the phase moved on, an action from a non-current player) must throw `GameError`, never change state. Test in Task 7/8: `rejects moves out of turn and out of phase`.
2. Blitz on a territory where `from` has exactly 2 armies does one exchange at most and stops; `attack` from a territory with 1 army throws. Test in Task 8.
3. A player who disconnects mid-turn with the timer Off stalls the game; the host's "End game" is the escape (platform), so `waitingOn` must name them. With the timer on, `onTimer` must finish every phase including `occupy` and a forced trade. Test in Task 10: `timer finishes a turn from every phase`.
4. Reinforce placements that name a territory you don't own, a zero/negative count, or a sum that isn't exactly `toPlace` must throw. Test in Task 7.
5. The deck running out (many trades) reshuffles the discard; if both are empty no card is drawn and nothing crashes. Test in Task 9.

**Interfaces:** `node scripts/build-map.mjs <world|realm>` rewrites the region between `// <generated>` and `// </generated>` in the map file with a `const SHAPES: Record<string, { path: string; label: [number, number] }>` and `const SEA: string`; the map file merges SHAPES into its territories. It prints `suggested adjacency differs: a–b` lines when shared edges disagree with `adj` (lanes excepted).

Algorithm (not determined by the signature):

```
for each landmass in coasts: seeds = territories whose seed lies inside it
  if seeds.length === 1: shape = landmass polygon
  else: Delaunay.from(seeds).voronoi([0,0,w,h]); cell_i ∩ landmass (polygon-clipping.intersection)
path = polygon rings → "M…L…Z", coordinates rounded to 1 decimal; label = pole of the largest ring's centroid (area-weighted)
neighbours = cells sharing an edge of length > 2 units
```

**Interfaces (Produces — every later task uses these):**

```ts
type Phase = 'draft' | 'reinforce' | 'attack' | 'occupy' | 'fortify' | 'over';
interface Battle {
  seq: number;
  attacker: string;
  defender: string;
  from: string;
  to: string;
  mode: 'roll' | 'blitz';
  attackDice: number[];
  defendDice: number[];
  attackerLost: number;
  defenderLost: number;
  conquered: boolean;
  ended: boolean;
}
interface RiskState {
  map: MapId;
  goal: 'missions' | 'domination';
  cardSets: 'rising' | 'fixed';
  turnSecs: number;
  seats: string[];
  neutral: boolean;
  owner: Owner;
  armies: Record<string, number>;
  phase: Phase;
  turn: string;
  round: number;
  toPlace: number;
  returnTo: 'attack' | null;
  drafts: Record<string, { left: number; placed: Record<string, number> | null }> | null;
  occupy: { from: string; to: string; min: number; max: number } | null;
  takenThisTurn: number;
  deck: Card[];
  discard: Card[];
  hands: Record<string, Card[]>;
  setsTraded: number;
  missions: Record<string, Mission> | null;
  eliminated: string[];
  eliminatedBy: Record<string, string>;
  battle: Battle | null;
  battleSeq: number;
  run: { from: string; to: string; lost: number } | null;
  best: {
    battle: { pid: string; value: number; text: string } | null;
    conquest: { pid: string; value: number } | null;
  };
  log: RecapEvent[];
  actBy: number | null;
  winner: string | null;
}
interface RiskTableView {
  map: MapId;
  goal;
  cardSets;
  seats;
  neutral;
  owner;
  armies;
  phase;
  turn;
  round;
  toPlace: number;
  occupy;
  handCounts: Record<string, number>;
  nextSetValue: number | null;
  draftDone: string[];
  eliminated: string[];
  battle: Battle | null;
  actBy: number | null;
  log: RecapEvent[] /* last 12 */;
  missions: Record<string, Mission> | null /* only when over */;
  winner: string | null;
}
interface RiskView {
  hand: Card[];
  mission: Mission | null;
  draft: Record<string, number> | null;
  draftLeft: number;
}
type RiskAction =
  | { type: 'draft'; placements: Record<string, number> }
  | { type: 'trade'; cards: [string, string, string] }
  | { type: 'reinforce'; placements: Record<string, number> }
  | { type: 'attack'; from: string; to: string; mode: 'roll' | 'blitz' }
  | { type: 'occupy'; n: number }
  | { type: 'endAttack' }
  | { type: 'fortify'; from: string; to: string; n: number }
  | { type: 'endTurn' };
export const risk: GameModule<RiskState, RiskAction, RiskView, RiskTableView, RiskOptions>;
```
