# Catan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Catan (`packages/games/catan`) to Jackdaw: 3–6 players (paired turns at 5–6), offers
with counters, Balanced/Random/Beginner boards, phone + TV + lobby seats in the "Colour print" look.

**Architecture:** Pure rules over a generated hex layout (`geometry.ts`, stable corner/edge ids),
split into focused modules (board generation, placement, longest road, trading) composed by
`rules.ts` into a `GameModule`. Public state only through `getTableView`; hands, development
cards and stolen resources only through `getPlayerView`. Screens in `src/ui/` draw an SVG board
from the same layout.

**Tech Stack:** TypeScript, Zod 4.6.7, Vitest, React 19, Next.js 16, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-23-catan-design.md` (mockups `mockups/catan.html`).

## Global Constraints

- No change to `GameModule`, the lobby state machine or the protocol (`packages/engine`).
- All randomness through the injected `Rng` (`next`, `int`, `pick`, `shuffle`); no `Math.random`, no clock reads in rules.
- `getTableView` carries no hand contents, development card types, VP cards (until over), deck order, or stolen resource.
- Options exactly: `board: ['Balanced','Random','Beginner']`, `points: ['10','8','12']`, `robber: ['Standard','Friendly']`, `turnTimer: ['Off','1 minute','2 minutes','3 minutes']`; defaults Balanced, 10, Standard, Off.
- Meta: id `catan`, name `Catan`, 3–6, category `board`, minutes `[60, 120]`, complexity 2. Art `{ band: 'tenne', field: 'semee', glyph: 'hexes' }`.
- Classic: 19 tiles / 54 corners / 72 edges, 9 harbours, 19 of each resource, dev deck 14/5/2/2/2. Big: 30 / 80 / 109, 11 harbours, 24 each, dev deck 20/5/3/3/3. Token orders as in the spec.
- Seat colours in order: red, blue, white, orange, green, brown.
- No literal colours outside the token block at the top of `catan.css`; Tailwind for layout only; taps ≥ 44px; `prefers-reduced-motion`; check 375/768/1280/1920 day and dark; TV per STYLE_GUIDE "TV sizes".
- Commits authored as Lesia with **no** Co-Authored-By trailer. Before each commit: `pnpm format:check && pnpm lint && pnpm typecheck && pnpm test` (plus `pnpm build:check` when web code changed). Never commit `apps/web/next-env.d.ts`.
- Credit: "Based on CATAN by Klaus Teuber. CATAN is a trademark of CATAN GmbH; this is a fan version for friends, with our own art."

## Review Focus

1. A double-tapped or stale move (second `roll`, `build` after the phase moved on, `accept` of an offer already completed or withdrawn) must throw `GameError` and never change state. Test in Task 4/6: `rejects stale and repeated moves`.
2. A trade accepted after the maker or partner spent the cards must be refused, not go negative. Test in Task 6: `re-checks both hands when a trade completes`.
3. A player who leaves mid-discard stalls a 7 with the timer Off; `waitingOn` must name exactly the players still owing cards so the host can see who. With the timer on, `onTimer` finishes the discard. Test in Task 7.
4. Road building with no legal edge, or with 0–1 roads left, must not trap the player in `roadBuilding`. Test in Task 5: `road building with nowhere to build ends`.
5. Every card stays accounted for (bank + hands = 95 or 120 per resource), across monopoly, short banks and discards. Test in Task 7's fuzz.
